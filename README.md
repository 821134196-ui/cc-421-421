# 工装夹具借用与寿命记录系统

虚构工厂「鸿鹄精密一厂」的工装夹具全生命周期管理：台账、工位/机型适配、
借用申请、扫码借还、归还点检、维修复核、保养提醒、跨线调拨、报废判定。

**零第三方依赖**：Python 3.10+ 标准库（`http.server` + `sqlite3`）+ 原生前端。

## 单条本地启动命令

```bash
python3 app.py
# 浏览器打开 http://127.0.0.1:8000
```

首次启动自动：

1. 在 `data/factory.db` 建表并播种虚构数据（3 条产线、5 个工位、3 种机型、9 名员工、8 件夹具）；
2. 生成 **领用 / 维修 / 报废 / 逾期** 全链路样例；
3. 启动进程内守护线程，每 30 秒扫描保养到期与归还逾期，写入提醒与处置单。

可选参数：`--host 0.0.0.0`、`--port 8080`、`--db 自定义.db`。
删除 `data/factory.db` 即可恢复全新演示数据。

## 测试

```bash
python3 -m unittest discover -s tests -v
```

覆盖五条核心规则（共 10 个用例）：

| 规则 | 用例 |
|---|---|
| 寿命累计 | 每次领用 `use_count+1`；达阈值自动开超寿命处置单并禁止再申请 |
| 适配校验 | 工位不生产机型、夹具不适配机型、冻结/维修中预订均被拒 |
| 领用竞争 | 双线程屏障并发抢同一夹具，恰一人成功（原子条件 UPDATE + 进程锁），寿命只计一次 |
| 维修复核 | 承修人本人/操作员复核被拒；另一名维修班或工段长通过后才解冻 |
| 跨线权限 | 操作员禁止发起/审批；仅调入线工段长可批准，通过后夹具换线并开处置单 |
| 附加 | 点检不合格同时生成「变形」「定位销缺失」处置单；逾期归还生成逾期单 |

## 业务规则

- **申请**：夹具必须同时满足 ① 工位生产该机型 ② 夹具适配该机型 ③ 夹具 `available`
  且未冻结、未超寿命；操作员仅可申请本产线工位。
- **批准**：工段长/维修班批准后夹具锁定为「已预订」，他人无法再申请。
- **领用**：扫码确认，原子更新 `reserved → in_use`，累计使用次数 +1。
- **归还**：先进入「已归还待点检」，夹具不回可用池。
- **点检**：合格才解锁回可用；不合格 → 冻结后续申请、转维修，
  发现描述含「变形」「定位销」分别自动生成处置单。
- **维修**：承修人提交完成后，**必须由另一名员工复核**；驳回则返工，夹具保持冻结。
- **报废**：超寿命/变形/缺销处置单由工段长在报废页判定（页面固定显示
  累计次数、寿命阈值、最近点检）；批准后夹具报废，未结申请自动驳回。
- **跨线调拨**：维修班发起、**调入线**工段长审批，通过后改挂新工位/产线并生成调拨处置单。
- **逾期**：超过应归还时间未还，后台任务与归还动作都会生成逾期处置单。

## 五类处置单

`deformation` 夹具变形 · `pin_missing` 定位销缺失 · `over_life` 超寿命 ·
`transfer` 跨线调拨 · `overdue` 归还逾期（报废审批页另含 `scrap` 判定入口）。

## 目录结构

```
app.py                 # 单条启动命令入口
system/
  db.py                # SQLite schema 与连接（WAL + 进程锁）
  seed.py              # 虚构工厂主数据
  sample.py            # 首启样例：领用/维修/报废/逾期
  service.py           # 全部业务规则与状态机
  server.py            # 标准库 HTTP 服务 + JSON API + 后台任务
static/
  index.html styles.css app.js   # 石墨灰 / 信号黄 / 冷白 界面
data/
  factory.db           # SQLite（首启生成）：夹具寿命与全部申请/单据
  photos/              # 本地点检照片（支持上传 svg/png/jpg）
tests/test_system.py   # 五条核心规则测试
```

## 界面

- **夹具台账**：每件夹具一张等轴测 SVG 小图（颜色随状态变化，冻结显示红叉光束，
  报废显示灰叉），下方寿命进度条（绿 → 信号黄 ≥80% → 红 ≥100%）。
- **申请队列**：按状态过滤，行内完成批准 / 驳回 / 领用 / 归还 / 点检（含照片上传）。
- **工位匹配**：先校验工位是否生产机型，再逐件夹具判定「在位/本线可调入/跨线/冻结/超寿命」。
- **借还扫码**：双扫码框，大号字体突出**工位编号**与**夹具编号**，支持扫码回车自动带出信息。
- **保养计划**：进度条 + 到期标记，一键登记保养并自动滚动下一计划点。
- **报废审批**：卡片固定三格显示**累计使用次数 / 寿命阈值 / 最近点检结果**，
  下方展示点检照片与处置说明，工段长批准或驳回续用。
- 左下角可切换当前操作人身份（操作员 / 维修班 / 工段长、不同产线）以体验权限差异。
